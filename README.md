# Ground Run

Single-page tool for S-92 ground runs: HSS vibration polar chart (Engine 1 / Engine 2), MR Balance and TR Balance records.

- Works offline after first load (service worker).
- On iPad: open in Safari → Share → **Add to Home Screen**.
- Data is stored only on the device (browser storage). Use **Export data (JSON)** after each job.

> Not verified. For use as a support tool only. Always follow the AMM.
